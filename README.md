# Atrapa las estrellas

Mini-juego desarrollado en Python con Pygame para la actividad del curso AI For Devs Jr. 3.

## Objetivo

Controlar una nave espacial para atrapar estrellas, obtener puntos y evitar meteoritos. El jugador comienza con tres vidas y pierde una vida cuando choca con un meteorito o deja pasar una estrella.

## Requisitos

- Python instalado.
- Biblioteca Pygame.

## Instalación

Abre CMD en la carpeta del proyecto y ejecuta:

```bash
python -m pip install pygame
```

## Cómo ejecutar

El archivo principal es `Tarea2-CursoAIForDevsJr.3-RenzoGenovez.py`.

Ejecuta el juego con:

```bash
python "Tarea2-CursoAIForDevsJr.3-RenzoGenovez.py"
```

## Controles

- Flecha izquierda o A: mover la nave a la izquierda.
- Flecha derecha o D: mover la nave a la derecha.
- Enter o Espacio: iniciar o reiniciar la partida.
- Esc: salir.

## Funcionalidades

- Puntuación de 10 puntos por estrella atrapada.
- Meteoritos que reducen vidas.
- Tres vidas iniciales.
- Dificultad progresiva.
- Pantalla de inicio y pantalla de fin de partida.
- Récord guardado localmente en `record.txt`.
- Fondo espacial generado mediante código.
